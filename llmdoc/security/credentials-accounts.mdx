# 凭据引用、登录与授权流程

CredentialReference 表达凭据来源，配置持有引用而非秘密值。Local provider 在操作时解析环境/.env 等来源，账号登录授权则有自己的流程和持久状态；匿名标识也不能代替资源权限。

空值视为未提供，轮换与注销必须根据实际读取时点生效。把秘密复制到 config、Session、诊断或客户端展示会绕开引用生命周期；缓存也不能无期限保留旧授权。

修改凭据消费时检查失败、取消、登出与轮换，错误只说明所需来源，不回显秘密。Registry OAuth 的 epoch/refresh 是独立协议边界，进入其 owner 后再判断何种缓存仍有效。
