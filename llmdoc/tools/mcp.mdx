# MCP外部工具资源

MCP client 将外部工具和资源接入 Harness；协议转换不是信任提升。远端提供的 schema、文本或 resource 不能代替本地执行授权，原生工具管线仍负责消费边界。

连接生命周期必须与注册内容一致。断线、重连或 scope 处置后，旧工具与 resource 不能继续看起来像可用的当前实例；重连也不能把旧调用的迟到结果结算到新身份。

修改适配时检查工具定义转换、返回值、资源如何进入上下文，以及连接失败后的清理。仅列出远端工具不足以证明可执行；具体传输与服务器配置在 MCP 包权威维护。
