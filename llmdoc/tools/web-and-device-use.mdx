# 搜索抓取与浏览器/桌面控制

Web search/fetch 提供信息；browser/computer use 控制有状态设备。信息 provider 的组合不能被误解为允许任意切换桌面控制 provider；设备 registry 的排他性与 Session 资源所有权需单独维护。

浏览器或原生设备的控制资源要随实际 session/scope 清理。远端搜索结果不授予本机执行权，MCP/native 适配的支持范围和失败语义也不可混为一种通用能力。

修改设备适配时检查唯一 provider、目标归属、取消和 dispose；修改搜索抓取时检查传输和内容边界。真实 GUI 成功与协议替身成功是不同证据，涉及用户可见动作时需要真实宿主验收。
