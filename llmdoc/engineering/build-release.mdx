# 构建图、安装分发与发布产物

Source plane 的类型/单测与 artifact plane 的安装/运行是不同证据。TS 编译、tsdown/Vite 打包、native资源和 npm/Desktop/Python 发布家族共同决定最终产物，源码别名通过不能代替已发布入口。

构建依赖图、Host/Client分离及platform资源应由正式脚本管理；不能为单个consumer临时复制一套实现。打包后的 manifest/exports、资源定位与真实安装 smoke 需要与生成物一致。

修改分发时确认受影响发布家族及目标平台，再运行对应产物验证。源码测试不覆盖签名/安装/更新恢复；发布操作与本地构建也应分别记录，不把生成文件存在当成已上传。
