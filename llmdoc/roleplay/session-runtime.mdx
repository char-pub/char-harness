# Roleplay持久请求与Story提交

Roleplay driver 使用现有 Session store，却不挂编码 AgentLoop/system prompt。Opened 固定输入，requested 在派发前持久化实际有序消息与有效模型配置，settled 记录成功结果或失败尝试；pending 不是已经提交的剧情。

只成功结算推进 Story，失败与取消保留尝试证据。恢复 pending 请求不会自动重发模型；重复命令需匹配原身份与输入。开始持久提交后取消可能与结果不确定相遇，应重读日志而不是自信回滚。

投影重建和流终止检查都属于恢复契约，成功流不能在终止后继续输出。改动必须验证实际 Loader、JSONL、请求与日志对账；纯回放通过不足以证明持久层或模型派发正确。
