# PTC typed程序执行

PTC 将 typed 程序交给明确的 runtime Provider；resolve 与 run 分离，工具绑定及结果序列化遵循公开契约。Node 子进程或 Python 运行时实现隔离执行，不允许把同一程序改为任意 Host eval。

Host binding 仍受原工具授权约束，程序内调用不能绕过审批。输出账本、大小限制、取消和 channel 关闭需一起处理，否则程序结束可能留下未结算副作用或被误读的部分结果。

修改 runtime 时检查类型输入、跨进程协议、完整输出与异常/取消路径；使用它的 Workflow 和工具也需审查。支持语言与具体绑定签名从源码恢复，不在知识层复制目录。
