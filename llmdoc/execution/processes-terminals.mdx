# 子进程、shell与持久PTY

Subprocess seam、一次 shell 调用与跨调用持久 PTY 有不同资源生命周期。子进程退出、stdout/stderr 排空、终端 Session 保留和整个进程树停止不是同一事件。

取消必须按实际进程/终端 owner 收口，不能只抛 AbortError 就把仍持有管道的后代留在后台。输出截断、spill 与返回结果应保留彼此关系，而不把丢失的输出冒充空成功。

修改进程能力时检查 shell 选择、执行世界、继承句柄、超时和 dispose。测试须独占端口/临时路径/子进程；在单独运行时通过而并行互扰的用例仍是缺陷。
