# TS/Python SDK与ACP自动化

TypeScript/Python SDK 都投影同一 Host 协议与运行模型。SDK 选择同版本 dsh runtime 和明确 profile；Python runtime wheel 是分发载体，不是另一个业务实现或任意 config launcher。

ACP 面向机器自动化，其批准与交互语义不能伪装成人类 Web UI 的点击。跨语言 API 的同名方法也需要保持真实 wire 行为，类型可编译不足以证明 runtime 已被正确打包。

修改 SDK 时检查公开 compiled entry、安装后资源查找、协议失败和进程退出。测试直连源码只覆盖开发面，不能据此声明 npm/wheel 与目标平台可用。
