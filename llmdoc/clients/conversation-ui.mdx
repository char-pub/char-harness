# Conversation、Slots与可见交互

Host 投影持有会话事实，Client models 和 target-neutral conversation 层负责呈现，chat/trajectory 通过 typed slots 组合。Feature 之间不直接借用对方内部组件充当契约，否则生命周期和状态所有权会随 UI 拆分漂移。

用户正在编辑的输入是本地草稿，不是已提交 Session event。异步结果必须绑定原对象，切换会话或账号后不得覆盖新草稿；取消和失败应保留可恢复输入。

主题、locale 和视觉 primitive 不能仅凭 DOM 存在验收。真实宿主可能使用不同背景或窗口承载方式，关键操作、正文对比度与错误恢复需实际截图/点击验证；这是与协议测试独立的证据。
