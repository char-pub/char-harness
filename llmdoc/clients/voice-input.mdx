# 语音输入与瞬时音频

语音输入分离 capture、speech Provider 与转写插入目标。音频是瞬时输入还是持久附件应由明确流程决定，不能因支持上传就默认保留麦克风内容。

Provider resolve 后应维持该选择；失败不暗换另一服务。转写结果必须绑定发起时的会话/草稿，晚到内容不能覆盖用户切换后正在编辑的文字。

修改语音时检查停止录制、取消、worker处置、权限失败和草稿归属。固定音频或mock协议验证只证明控制流，实际麦克风与宿主授权需另有验收。
