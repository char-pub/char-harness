# 遥测、反馈与诊断

Telemetry、feedback 和诊断是不同出口，事件存在并不自动授权采集。OTel 的独立 channel 管理自己的队列和销毁期限，产品统计与 Session 内容采集不能共享一个宽泛的“可上报”判断。

Session 日志、用户反馈与调试 Inspector 可能包含敏感事实，应按各出口既定截取/脱敏规则处理。诊断不得把凭据或原始聊天混进普通错误信息。

修改观测能力时检查实际发送字段、取消/flush deadline和停用后的资源释放。计数面板或mock收件成功只证明传输，不证明用户授权范围；字段列表从实际collector而非知识文档恢复。
