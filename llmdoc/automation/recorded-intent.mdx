# Goal、Plan、Todo与人类意图

Goal、Plan 和 Todo 表达不同的人类意图。Goal 持久阶段和当前进程的激活状态不同；Plan 的审阅不自动批准其中每个副作用；Todo 是工作记录，不能被当成已执行证据。

自动继续的 driver 只能根据明确的 Goal 状态和运行边界推进，不能从一段自然语言或 UI 显示推断持久状态已改变。历史 revision 的折叠与新的用户修改需要保持可解释。

变更这些能力时分别检查持久记录、折叠结果、当前执行与客户端显示。停止或取消并不总能撤回已提交动作；精确状态机和命令由所属 schema/README 恢复。
