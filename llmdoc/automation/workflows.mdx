# Workflow脚本编排

Workflow 通过声明的 seam 和 PTC engine 执行编排，沿调用 Session 的执行世界与授权运行。脚本可以组织工具和委派，但不能另开绕过 sandbox/审批的 Host eval 通道。

Workflow run 的状态不是普通子代理状态的别名；循环、取消、结果和资源处置由 engine 明确承担。前端看到运行中、后台 job 存在或模型说已完成，都不足以证明 workflow 结算。

修改编排时同时核对 typed bindings、子操作授权、输出界限与取消传播。新 engine 应遵循同一契约；不要把测试中直接挂载某个实现当成产品组合入口。
