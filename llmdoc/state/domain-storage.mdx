# 非Session存储与schema迁移

非 Session 领域数据通过 Storage hub 与 typed domain 存储；JSON/SQLite backend 管介质，domain 管含义。普通键值记录没有自动获得 append-only 日志的事实或回放语义。

迁移由拥有该 schema 的 domain 明确承担，SQLite 版本单调推进。清缓存、重建索引与迁移持久领域状态不能共享一个含糊的“重置数据”动作。

修改存储时检查 schema 版本、部分写入与关闭/恢复路径，确认需要的是领域状态还是 Session event。Backend 可替换不代表所有实现有相同事务和持久性保证，消费者应依公开契约行事。
