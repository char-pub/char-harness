# char.pub Harness 准备目标

建立独立 Runtime monorepo，以 DeepSeek Harness 的插件、会话日志和模型提供方为起点。char.pub 持有创作模型、纯求值和上下文组装；这里持有模型网络调用、决策适配、实际会话和行为确认。

当前目标是基础准备和可验证的最小消费入口，不承诺完整游戏客户端。新增 roleplay profile 使用明确的能力列表，不继承 coding profile 的全部工具。

验收案例：读取固定创作产物，以固定决策完成一次状态确认和上下文准备；把输入、计划和状态操作记录成可重放事件。未知判定不触发否定分支，取消不提交剧情事实，重复请求不重复效果。Jev 使用官方 API；Laya 在项目身份核实后接同一用途接口。
